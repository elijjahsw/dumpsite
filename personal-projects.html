LOG #3: ARDUINO ANALOG READ ANALYSIS

This exercise was used to replace the use of the DMM and to allow the Arduino to display the voltages on the serial monitor on the Adruino IDE.

  • Hardware:Arduino Uno, Solderless Breadboard and 220Ω Resistor 2x
  • Language:C++ / Arduino IDE
  • Status:Passed

There really isn't much to show here, so here's an explanation of what's going on. The Arduino Uno hardware uses a 10-bit ADC to sample incoming analog voltage. A 10-bit resolution provides 1023 discrete levels (0-1023), scaling inputs from '0' (0v) to '1023' (5v). The value printed on the Serial Monitor is the representation of the 10-bit integer reading. A raw reading of '511' represents approximately half scale calculated via the linear conversion formula.

// Test Script


    int pin= A3;
    int A=0;
    float b =0;
    float y=0;
    void setup() {
  pinMode(pin, INPUT);
  Serial.begin(9600);
}

void loop() {
  b=analogRead(pin);
  Serial.println(b);
  delay(2000);
  y= b* (5./1023.);
  Serial.println(y);
  delay(500);
}

LOG #4: ARDUINO IF STATEMENT VERIFICATION

This exercise was used to verify conditional threshold logic in C++, turning an output pin HIGH or LOW based on measured analog voltage levels.

  • Hardware:Arduino Uno, Solderless Breadboard, 220Ω Resistor 2x, 10,000Ω Resistor and blue LED
  • Language:C++ / Arduino IDE
  • Status:Passed

As the same as last time, this is more of me demonstrating conditional hardware control. Basically the Arduino samples the input state and evaluates it against a defined threshold. When the condition is TRUE(1), it triggers a state change on pin 6, supplying 5 volts to drive the LED circuit until the condition is FALSE(0).

// Test Script


    int x=A2;
int b=0;
int pin=3;
float volt=0;

    void setup() {
  pinMode(x,INPUT);
pinMode(pin,OUTPUT);
Serial.begin(9600);
}

void loop() {
  b=analogRead(x);
  volt=b* (5./1023.);
  Serial.println(volt);
  delay(500);
  if(volt>3.00){
    digitalWrite(pin,HIGH);
    }
    else{
      digitalWrite(pin,LOW);
      }

    }

LOG #5: CONTROL FLOW-FOR VS WHILE LOOPS

Implementing C++ control flow structures(for and while loops) to excute iterative logic control digital output states(LEDs) based on incremented counter thersholds.

FOR LOOP

  • HARDWARE:Arduino Uno, Solderless Breadboard, 220Ω Resistor 2x, red and yellow LED
  • LANGUAGE:C++ / Arduino IDE
  • STSTUS:Passed

Demonstrating deterministic iteration in C++ using a for loop. Unlike condition-driven execution, the for loop initializes a counter variable, evaluates a termination condition, and executes an increment step per iteration. This allows the micro-controller to run a precise, predefined number of output cycles—such as blinking an LED or pulsing a pin sequence—without relying on external sensor input to break the execution block.


WHILE LOOP

  • HARDWARE:Arduino Uno, Solderless Breadboard, 220Ω Resistor, and red LED
  • LANGUAGE:C++, Arduino IDE
  • STATUS:Passed

Demonstrating condition-driven iteration in C++ using a while loop. Unlike a deterministic for loop, execution continues indefinitely as long as the relational expression evaluates to TRUE. The micro-controller executes the loop body and updates the evaluation variable internally on each cycle, maintaining an output state until the test condition breaks.
