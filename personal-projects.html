Fig 1.3 This circuit was relatively easy to construct so there wasn't much troubleshooting. Incase you didn't know, the LDR's resisor value isn't fixed, it changes based on ambient light. In total darkness, it's resistance can go all the way up to 1M(mggaohm) or higher. Under bring light, it's value can drop to 1k or less. 10kohm is generally considered the sweet spot based on a couple calculations, all of which I won't show as of now.

LOG #5: 2-Axis Pan-and-Tilt Servo Gigmal (Joystick HMI)

Designed and built a dual-axis mechatronic control system driven by an Arduino microcontroller. The system fetures an analog 2-axis joystick acting asn a Human Machine Interface (HMI) to command independant pan-and-tilt servo motors in real time, paired with an integrated peizo buzzer for state feed-back.

  • Hardware: Breadboard, active buzzer, sevos2x, and joystick
  • Language: C++ / Arduino IDE
  • Stataus: Passed

I origially intended to construct a mini crance mechanism with this setup but lacked the mounting hardware to couple the servos. The control systems interfaces an analog joystick with dual PWM servos using scaled coordinate mapping. Durning initial testing, only the y-axis servo responded to joystick displacement. To isolate the issue, I printed the raw ADC voltage readings for both axis to the Serial Monitor. The matching continous outputs eliminated physical faults, such as loose jumper wires, bad breadboard terminals or a dead potentiometer tracks. After verifying the hardware layer I innspected the code structure and identified a variable mismatch: the x-axis servo object was not properly decleared in the main execution block. Correcting this instance restored synchronized dual-axis response.

Unlike continous DC motos or fixed sweep servo motors, a stepper motor rotates through discreat micro-steps controlled via microcontrollerdriber board allowing exact repeatability and position verification trhough sequential pulse trains. Directional logic and motion states are toggled via a physical interface pushbutton.

  • Hardware: BreadBoard, stepper motor, motor driver, and pushbutton
  • Language: C++ / Arduino IDE
  • Status: Passed

This was a straightforward build focused on digital input handling a step-sequence control. Bidirectional control of the stepper motot was achived by interfacing a tatical pushbutton with the microcontroller, the softwre logic samples the button state to toggle the step sequence direction continously upon each trigger event.

LOG #7: Transistor DC Motor Switch with Flyback Diode

Low-voltage microcontroller switching of an inductive load, featuring flyback diode protection to clamp back-EMF transient voltage spikes.

  • Hardware: DC motor, flyback diode, transistor, power supply module and 9V battery
  • Language: C++ / Arduino IDE
  • Status: Passed

Had to use the conventional method of setup because I lacked the motor driver to run this motor. A 2N2222 NPN transistor was configured as a low-side solid-state switch to drive the DC motor. To protect the circuit from inductive kickback (back-EMF) which occurs when the motor's collapsing magnetic field releases stored energy upon de-energization a, flyback diode was wired in reverse bias across the motor terminals. This provides a safe recirculation path for the high-voltage spike, preventing damage to the transistor and microcontroller.
